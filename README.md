🧠 Transparent AI Decisioning Framework

This repository implements a transparent reasoning agent based on the Toulmin model of argumentation, powered by hierarchical sub-question decomposition and auditable probabilistic confidence propagation.

It is designed to demonstrate state-of-the-art structured reasoning using LLMs (quantized LLaMA models), with a focus on:

Explainability

Auditability

Governance & controls

Human-in-the-loop safety

This framework supports any decision domain:

Heavy equipment maintenance

Lending

Medical or financial decisions

Risk assessment

Corporate operations
…and more.

✨ Key Features
🧩 Hierarchical Reasoning

The framework automatically decomposes a decision into a tree of sub-questions:

S1 - Equipment condition
  ├─ S1.1 - Hydraulic pump temperature
  └─ S1.2 - Bearing wear

S2 - Failure risk
  └─ S2.1 - Probability of failure within 30 days

S3 - Production & cost impact
S4 - Policy & safety constraints


Each leaf is answered using a Toulmin argument generated by the LLM.

📐 Toulmin Argument Structure

Every claim is represented as:

Claim
Data
Warrant
Backing
Qualifier
Rebuttals


These are returned as strict JSON, suitable for logging and audit.

📊 Probabilistic Confidence

Every claim includes a numeric confidence score (0–1).

⚠️ The textual confidence label is NOT trusted.
The system always recomputes it from the numeric value.

♻️ Bottom-Up Confidence Aggregation

Internal nodes aggregate confidence from children using weighted log-odds, ensuring:

Propagation of uncertainty

Traceable, auditable math

Domain-dependent weighting (e.g., risk > cost)

🔐 Governance Gate

If final confidence is below threshold, the agent flags:

requires_human = True


Otherwise, high-confidence claims may trigger actions or tool calls.

🧰 Installation
1. Install dependencies
pip install -r requirements.txt

2. Install Ollama (if not already installed)

https://ollama.ai

3. Pull a quantized LLaMA model

For example:

ollama pull llama3:8b


You can use smaller quantized models for speed, e.g.:

ollama pull llama3:8b-q4

4. Run the demo
python3 main.py

🛠️ How It Works
Step 1 — Define the Decision Context

The context is a structured object:

CASE DOMAIN
CASE SPECIFIC INFORMATION
DECISION RULES AND POLICIES
GENERAL KNOWLEDGE


Example domain: Heavy Equipment Maintenance

Step 2 — Generate Sub-Questions

The LLM produces a hierarchical tree of sub-questions.

Step 3 — Generate Toulmin Blocks

Each leaf node becomes a Toulmin argument via a second LLM call.

Step 4 — Aggregate Confidence

Internal nodes combine child confidences using a weighted log-odds model.

Step 5 — Final Decision

An actionable Toulmin block is created:

final claim

final confidence

whether human approval is needed

📈 Example Output
=== Final decision summary ===
Final claim: Perform maintenance now rather than delaying by one month.
Final confidence: 0.87
Requires human approval: False


All reasoning steps are printed as structured JSON, suitable for:

Logging

🔒 Governance & Safety

This framework supports:

Human-in-the-loop

Confidence thresholds

Action triggers only above threshold

Full traceability

If final_confidence < threshold, no action is taken without human endorsement.
